Step-by-step guide to getting started in Ethereum development and a survey of useful resources cobbled together from various other guides.

# Recommended step-by-step:

1. [Do introductory reading](https://blog.remilia.org/article/ethereum-starter-pack/#Understand) if new to the concepts of blockchain, smart contracts and decentralized finance.
2. Complete [CryptoZombies walkthrough](https://cryptozombies.io/?ref=blog.remilia.org) to learn solidity syntax and NFT concepts:
3. Do [Solidity course on Chainshot](https://www.chainshot.com/learn/solidity?ref=blog.remilia.org) to cement your understanding of smart contracts
4. Walkthrough building a full React dApp: [Complete Guide to Full Stack ETH Development](https://dev.to/dabit3/the-complete-guide-to-full-stack-ethereum-development-3j13?ref=blog.remilia.org) \- [Video Course](https://www.youtube.com/watch?v=a0osIaAOFSE&ref=blog.remilia.org)
5. Familiarize yourself with [Smart Contract security practices](https://yos.io/2019/11/10/smart-contract-development-best-practices/?ref=blog.remilia.org) and run through [Ethernaut hacking wargame](https://ethernaut.openzeppelin.com/?ref=blog.remilia.org) to test your understanding.
6. Setup a comprehensive [production stack](https://github.com/austintgriffith/scaffold-eth?ref=blog.remilia.org)
7. Now use your stack to build increasingly complex dApps without guardrails:

- 🚤 [Follow the full Ethereum Speed Run](https://medium.com/@austin_48503/%EF%B8%8Fethereum-dev-speed-run-bd72bcba6a4c?ref=blog.remilia.org)
- 🎟 [Create your first NFT](https://github.com/austintgriffith/scaffold-eth/tree/simple-nft-example?ref=blog.remilia.org)
- 🥩 [Build a staking smart contract](https://github.com/austintgriffith/scaffold-eth/tree/challenge-1-decentralized-staking?ref=blog.remilia.org)
- 🏵 [Deploy a token and vendor](https://github.com/austintgriffith/scaffold-eth/tree/challenge-2-token-vendor?ref=blog.remilia.org)
- 🎫 [Extend the NFT example to make a “buyer mints” marketplace](https://github.com/austintgriffith/scaffold-eth/tree/buyer-mints-nft?ref=blog.remilia.org)
- 🎲 [Learn about commit/reveal](https://github.com/austintgriffith/scaffold-eth/tree/commit-reveal-with-frontend?ref=blog.remilia.org)
- ✍️ [Learn how ecrecover works](https://github.com/austintgriffith/scaffold-eth/tree/signature-recover?ref=blog.remilia.org)
- 👩‍👩‍👧‍👧 [Build a multi-sig that uses off-chain signatures](https://github.com/austintgriffith/scaffold-eth/tree/meta-multi-sig?ref=blog.remilia.org)
- ⏳ [Extend the multi-sig to stream ETH](https://github.com/austintgriffith/scaffold-eth/tree/streaming-meta-multi-sig?ref=blog.remilia.org)
- ⚖️ [Learn how a simple DEX works](https://medium.com/@austin_48503/%EF%B8%8F-minimum-viable-exchange-d84f30bd0c90?ref=blog.remilia.org)
- 🦍 [Ape into learning!](https://github.com/austintgriffith/scaffold-eth/tree/aave-ape?ref=blog.remilia.org)

Congratulations, you’re now an expert in the most lucrative & in-demand field in coding.

### Free Ethereum Gateway Hosting

Cloudflare offers a signup- and cost free hosted Ethereum Gateway –> [https://developers.cloudflare.com/distributed-web/ethereum-gateway](https://developers.cloudflare.com/distributed-web/ethereum-gateway?ref=blog.remilia.org)

All you need to do is use [https://cloudflare-eth.com](https://cloudflare-eth.com/?ref=blog.remilia.org) in your web3.js or ethers provider setup call. No signup, no API key. Just copy- and paste and you’re connected to mainnet.

You can use this as a replacement for Infura or Alchemy if you e.g. want to save API credits.

### Multicall - Bundle Contract Calls to Reduce Load

Multicall by Maker is a real “hidden” gem. It bundles multiple constant contract calls to reduce load on the Ethereum Node / Ethereum Node Provider you’re using.

You can i.e. do 10 requests but they’re then combined into just 1. This helps you save API credits when you’re e.g. using Infura.

[https://github.com/makerdao/multicall](https://github.com/makerdao/multicall?ref=blog.remilia.org)

You can use ethcall if you’re using ethers for a nice wrapper around multicall

[https://github.com/Destiner/ethcall](https://github.com/Destiner/ethcall?ref=blog.remilia.org)

### Debug Smart Contract Reverts

If you ever get stuck with hard to debug Smart Contract reverts definitely check out the Tenderly Explorer: [https://dashboard.tenderly.co/explorer](https://dashboard.tenderly.co/explorer?ref=blog.remilia.org)

Simply paste in your failed transaction, hit enter and you’ll get an in-depth stack trace of everything that happened up during the point your transaction was reverted.

This saved me hours while working with more complex Smart Contract calls in the context of Flash Loans…

### Walletlink - Extensionless Wallet Connection

If you’re looking for a simple way to connect your users wallets to your dApp without the requirement for browser extensions, you might want to take a look at WalletLink: [https://github.com/walletlink/walletlink](https://github.com/walletlink/walletlink?ref=blog.remilia.org)

Takes less than 5 minutes and 15 lines of code to setup
